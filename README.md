# GPUMD 与 NEP 学习记录

## 学习目标

学习 GPUMD、NEP 和 NepTrain 工作流程，逐步开发用于
Al–Mg–Si–Cu 铝基合金析出相、缺陷与力学性能研究的势函数。

## 学习路线

1. NEP 训练输入输出与关键字
2. DFT 单点计算与训练数据格式
3. 合金结构生成与数据筛选
4. 四元 NEP 初步训练
5. 独立验证、补充数据与迭代
6. 析出相、缺陷与力学模拟

## 文件说明

- notes：学习笔记与课程总结
- examples：小规模练习及输入文件
- scripts：数据处理和作业提交脚本
- results：结果图片与分析总结
- references：官方文档和文献链接

## 记录原则

每个练习记录目的、输入、软件版本、操作步骤、结果和待解决问题。
示例参数与经过验证的科研配置分别标明。
